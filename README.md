# Clinical RAG Brief Generator

A learning and portfolio project on public data: cited, reviewable competitive-landscape briefs for GLP-1 / incretin therapies in obesity. See [ProjectSpec.md](ProjectSpec.md).

Learning project on public data. Not medical advice.

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
copy .env.example .env          # then fill in real values
```
